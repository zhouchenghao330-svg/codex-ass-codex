# v0.2.7

- `/resume 会话ID [成员名]` 接入本机已有的独立 Codex 会话，自动恢复原目录、模型、思考强度、Fast 状态和原始权限，继续同一个 thread。无需进入项目目录。
- 用户提问、回复正文、工具详情和本地图片引用按原顺序显示，包括同一轮中的追加消息。分批读取历史，恢复本身不会启动模型；重复接入直接切到已有成员的底部。
- 支持在 `/resume` 后粘贴 Orca 的完整恢复命令，仅解析会话 ID，不执行 shell。命令中的提权标志不会替代原会话权限。
- 恢复的会话可使用当前 Room 公开消息和成员查询工具；原始标题保持不变，成员可单独改名。原生子代理通过父会话恢复。
- Room 自建会话的正式标题改为 `Room · 成员名`，随 `/rename` 同步；重新打开 Room 也会修正旧成员标题，避免历史列表显示内部宿主说明。
- 保留旧版界面对新增成员字段的存储兼容性。

接入前结束原窗口中的任务，之后选择一端继续；Room 不关闭原窗口，无法可靠判断其他独立进程是否同时使用同一会话。历史记录仍来自当前 Codex 数据目录，跨机器仅复制 ID 无法恢复。

验证包括 Python 回归、Rust 单测、真实 PTY 历史/滚动/重启测试，以及 `gpt-6.1-sol` / `medium` 的真实外部会话恢复、上下文回忆、Room 工具调用和重启续聊。
