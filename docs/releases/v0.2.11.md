# v0.2.11

- 输入框上方的成员名、模型、思考强度和 Fast 状态可直接点击。菜单贴近输入框展开，模型选择后继续选择强度；窄窗口分步显示，取消保留原配置。模型与强度使用单行选项，设置从下一轮生效。
- 成员切换统一使用弹层，支持点击成员名、Ctrl+B 和 `/members`。实时显示忙闲、目录及子代理归属，移除底部「成员」按钮和左侧栏，保留各自草稿和正文宽度。
- 任务完成或失败后增加未读结果提醒：小圆点、淡底色及 `[N 待查看]`。点击可定位未读成员；展开结果的末尾进入可见区域后清除。打开列表、查看旧消息或终端失去焦点时保留，按房间保存并跨重启恢复；焦点检测依赖终端上报。
- 回复标题改用淡色底区分成员，去掉正文旁的持续彩色竖条，保留成员身份色。
- Mermaid 代码块支持终端字符图：流程图、时序图、状态图、类图与 ER 图的受支持语法子集。流程图节点和连线标签支持 `<br>` 换行；横向放不下时明确提示并尝试纵向布局。未闭合、语法不支持或超出显示限制时保留源码。
- Mermaid 选区复制保留显示内容，整条消息转发和聊天存储保留原始源码。渲染器来自 OpenAI Codex，携带 Apache-2.0 许可及本地修改说明，`--licenses` 可查看许可。
- Markdown 代码块隐藏展示用围栏，保留代码正文、语法颜色与原始存储；修复嵌套代码块的显示和复制。
- 同步发布六个平台的预编译界面及校验文件。普通 `uv run codex_room` 使用 v0.2.11 成品；本地未发布修改仍通过 `--build-ui` 使用。
