首次提供预编译 Rust 界面：macOS Apple Silicon / Intel、Windows x64 / ARM64、Linux x64 / ARM64（静态 musl）。

克隆项目后执行 `uv run codex_room`。首次匿名下载对应平台的程序，校验 SHA-256 后缓存；后续复用缓存，不需要 Rust、Visual Studio 或 GitHub Token。准备 uv 和已登录的 Codex CLI 即可。

已有用户先退出 Room，执行 `git pull --ff-only` 后用原命令重开。成员、聊天和草稿保留；Release 不包含任何个人房间、登录或成员配置。

本版还加粗了成员回复左侧区分条，并让 @ 补全候选保持各成员自己的颜色；选中项通过箭头与加粗文字区分。

首轮跨平台检查暴露的 Windows 输出编码、后端管道 UTF-8 和 Linux 静态链接问题已修正。Windows 图片测试改用标准 file:///C:/... URL。v0.2.1 / v0.2.2 仅为失败构建标签，没有公开发布程序。

每个平台在 Actions 上执行启动器检查、Rust 单测和 --help 启动验证；这不等同于各平台完整人工交互验收。开发者修改 Rust 源码后使用 `uv run codex_room --build-ui`。

已知限制：拖选表格复制包含绘制边框和排版换行，长 URL 可能被拆行；消息存储的原始 Markdown 未变。
