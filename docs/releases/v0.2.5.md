新增 `/adhd` 窄栏居中阅读：正式界面采用阅读 Demo 的方案 5，聊天正文最多 92 列，保留原有颜色，不增加聚焦、压暗或悬浮效果。

`/adhd` 切换开关，`/adhd on`、`/adhd off` 明确设置。默认关闭，设置按房间保存，重启恢复；命令不会启动 Codex。输入框、成员栏和底部操作区域保留原布局。

正文按可用空间居中，窄窗口自动收缩。切换或调整窗口宽度时按消息内的文字位置恢复阅读位置，表格重新排版；宽度改变会清除旧选区。居中后的鼠标选字、复制和消息折叠沿用原有交互。

已有用户先退出 Room，`git pull --ff-only` 后运行 `uv run codex_room`，自动下载并校验本版界面；无需安装 Rust。原有成员、聊天、草稿和协作协议保留。
