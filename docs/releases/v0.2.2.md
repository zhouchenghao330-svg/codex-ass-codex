此版本仅为未发布的构建标签，请使用 v0.2.3。

首次提供预编译 Rust 界面：macOS Apple Silicon / Intel、Windows x64 / ARM64、Linux x64 / ARM64（静态 musl）。

在克隆的项目目录运行 `uv run codex_room`：首次自动从本 Release 匿名下载对应平台的程序、校验 SHA-256 后缓存；后续直接使用缓存，不需要安装 Rust，也不需要 GitHub Token。

准备 uv 和已登录的 Codex CLI 即可。已有用户先退出 Room，再 `git pull --ff-only`、`uv run codex_room`，原房间记录仍然保留。

开发者修改 Rust 源码后使用 `uv run codex_room --build-ui`。普通启动固定使用项目指定的 Release 版本，不读取“latest”。

本 Release 只包含界面程序与 SHA256SUMS，不包含任何个人聊天记录、成员配置或登录信息。Linux 使用 musl 静态链接；Windows、macOS 使用各平台的原生程序。每个平台在 Actions 上执行 Rust 单测、启动器检查和 `--help` 启动验证；这不等同于每个平台的完整人工交互验收。

已知限制：拖选表格复制会包含绘制边框与排版换行，长 URL 可能被拆行；消息存储中的原始 Markdown 不受影响。

首轮 CI 检查还暴露并修正了 Windows 非 UTF-8 重定向输出和 Linux musl 链接兼容问题。v0.2.1 仅为失败构建标签，未公开成品。
